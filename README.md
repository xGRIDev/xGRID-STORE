# xGRID-STORE [ React + Vite ] Front-End Project 

## Overview

This Project Front-End was build by own case based on React & vite. 

## Feature.

All these feature are about :
 - Filtering Search Basic on Topnav.
 - Filter Category on Section - List.
 - Route Navigate.
 - Dark Mode Theme.

## Tech-Stack & Library.

 - React V19.2.
 - Vite 8.2.
 - Motion Framer 13.
 - GSAP 3.15.
